# Plataforma Digital para Pequeños Emprendimientos artesanales
Este sistema aborda la problemática de los pequeños emprendimientos artesanales que no cuentan con herramientas digitales profesionales y dependen de métodos manuales o redes sociales informales como cuadernos o WhatsApp, previniendo la pérdida de información y fortaleciendo su visibilidad y credibilidad en el mercado digital.
# Objetivo general
Desarrollar una aplicación web utilizando la metodología Scrum para el manejo de catálogos de productos e inventarios básicos de pequeños emprendimientos artesanales en Guayaquil, con el fin de fortalecer su presencia digital y reducir la dependencia de redes sociales informales como canal de ventas.
